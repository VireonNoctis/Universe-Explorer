# Astra — Universe Explorer

Astra is a space-themed interactive astronomy explorer. It combines a React interface, a Three.js 3D scene, a Ruby/Sinatra JSON API, and links to external astronomy references.

## What works

- **Interactive 3D sky:** orbit with a drag, zoom with the wheel or the on-screen controls, and click celestial objects to focus the view.
- **Object detail profile:** object summary, measurements, related objects, and source links. Selecting an object moves the camera focus toward the right side so the information panel can occupy the left.
- **Live object search:** searches the built-in astronomy catalog and queries Wikipedia's public search API for additional reference results.
- **External reference details:** selected external results can open a summary profile with Wikipedia, NASA, and SIMBAD links.
- **Filters:** browse planets, exoplanets, stars, galaxies, nebulae, black holes, and moons.
- **Space UI:** dark observatory styling, constellation-like star field, procedural planet surfaces, responsive layout, Orbitron/Space Grotesk typography, and reduced-motion CSS support.
- **Small code footprint:** the application uses three code files; this README documents them.

## Requirements

- Ruby 3.1 or newer (Ruby 3.2+ recommended).
- Internet access in the browser for the CDN-hosted React, Babel, Three.js, and Google Fonts.
- Internet access on the server for external Wikipedia searches. The local catalog and object pages still work when external search is unavailable.

## Run locally

Install the two Ruby gems used by the server:

```sh
gem install sinatra puma
```

Start the app from the repository root:

```sh
ruby server.rb
```

Open [http://localhost:4567](http://localhost:4567).

You can choose another port with the `PORT` environment variable:

```sh
PORT=3000 ruby server.rb
```

The page HTML shell is generated by the Ruby route; there is no separate HTML frontend file. React/Babel and Three.js are loaded from public CDNs, while the application UI is in `app.jsx`.

## Application files

| File | Responsibility |
|---|---|
| `app.jsx` | React UI, Three.js scene, search interactions, filters, object details, and responsive app state |
| `styles.css` | Space-themed visual system, panel transitions, object cards, search UI, and mobile layouts |
| `server.rb` | Sinatra app shell, curated object catalog, JSON endpoints, and external knowledge search |

This keeps the app code to the requested frontend + CSS + backend. `README.md` is documentation.

## API endpoints

| Endpoint | Purpose |
|---|---|
| `GET /` | Serves the page shell and loads the app |
| `GET /api/health` | Basic server status and catalog size |
| `GET /api/catalog` | Initial catalog with positions, facts, references, and related-object IDs |
| `GET /api/search?q=earth` | Searches local catalog entries and external Wikipedia results |
| `GET /api/object/:id` | Looks up a curated catalog object by ID |
| `GET /api/lookup?title=Andromeda%20Galaxy` | Returns a local object or a Wikipedia summary-backed profile |
| `GET /api/source-search?q=exoplanets` | Returns source-search links for NASA, ESA, SIMBAD, and Wikipedia |

For example:

```sh
curl http://localhost:4567/api/health
curl 'http://localhost:4567/api/search?q=Andromeda'
curl http://localhost:4567/api/catalog
```

## Search and scientific sources

The initial catalog is a hand-curated starter index, not a complete database of every known object. Search supplements it with Wikipedia's public API and provides direct source links to NASA, ESA, the NASA Exoplanet Archive, SIMBAD, and the Event Horizon Telescope where relevant. Availability of external search depends on internet access and on the remote service.

Astronomy is an evolving field. Displayed values are intended as a helpful introduction and should be checked against the linked scientific source for research or educational work. Universe positions and sizes in the 3D scene are illustrative and are **not to scale**. “Observable universe” means the region from which signals have had time to reach us; it does not imply the app contains every object in that region.

## Troubleshooting

- **Page says the catalog is offline:** confirm the server is running and open `/api/health`.
- **External search has no results:** check server-side internet access. The built-in catalog remains searchable.
- **The 3D scene stays blank:** ensure browser internet access to jsDelivr CDNs and WebGL support are available; check the browser console for a CDN or WebGL error.
- **Port already in use:** run with a different `PORT`, such as `PORT=3000 ruby server.rb`.
